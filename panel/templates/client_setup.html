OpenConnect

{{ setup.command }}
  1. Install an OpenConnect client:
    • Windows: the OpenConnect GUI 1.6.2 installer, from the OpenConnect GUI project
    • Android: the OpenConnect 1.12 app, from F-Droid
    • macOS: brew install openconnect, with Homebrew
    • Linux: your distribution's openconnect package, or NetworkManager-openconnect to connect from the desktop's network settings; see openconnect
  2. Run the command, or add the server {{ setup.server }} in the client.
  3. {{ setup.sign_in }}
  4. Check that the client shows the same server key pin as this page before you trust it.

Cisco Secure Client

  1. Install Cisco Secure Client from the App Store on an iPhone, iPad or Mac, or from Google Play on Android.
  2. Add a connection to {{ setup.server }}.
  3. {{ setup.sign_in }}
  4. Cisco Secure Client does not check the pin. It trusts the server's certificate only when the device trusts the authority that issued it, so when this container issued the certificate itself, install that authority's certificate, ca.pem, on the device first.
